
# Claude extensibility course

## Install

Install Node.js 20 or newer, then install the course dependencies:

```powershell
npm install
```

Install Claude Code on Windows:

```powershell
irm https://claude.ai/install.ps1 | iex
claude --version
```

Start Claude Code once and complete the sign-in flow:

```powershell
claude
```

Optional: install **Marp for VS Code** for editor-based slide previews.
